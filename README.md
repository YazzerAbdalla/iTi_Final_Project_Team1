# iTi_Final_Project_Team1

# E-Commerce Platform (MEAN Stack)

This project was developed as part of my **ITI scholarship program** to apply the concepts and skills learned in the **MEAN stack** (MongoDB, Express.js, Angular, Node.js).

It represents a simplified **e-commerce platform** that demonstrates core functionality such as **user authentication, product listing, and shopping cart management**.
Although it does not include a payment gateway, it serves as a strong foundation for building a complete e-commerce solution.

---

## 🚀 Features

* **Authentication**

  * Secure user registration and login using **JWT** and **bcrypt**.

* **Product Listing**

  * Display products stored in MongoDB.
  * Basic product detail view.

* **Shopping Cart**

  * Add, remove, and manage items in the cart.

## 📂 Project Structure

The project is organized into separate folders for the **frontend** and **backend**:

```
ecommerce-mean/
│── backend/       # Express.js + Node.js + MongoDB
│── frontend/      # Angular + Tailwind CSS
```

---

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone <your-repo-url>
cd ecommerce-mean
```

### 2. Backend Setup

```bash
cd backend
npm install
npm run start
```

By default, the backend runs on **[http://localhost:5000](http://localhost:5000)**

### 3. Frontend Setup

```bash
cd ../frontend
npm install
ng serve
```

The frontend will be available at **[http://localhost:4200](http://localhost:4200)**
